# fruit-chaat-python
A beginner Python project that simulates a fruit chaat ordering system.

## Concepts Used
- Lists
- `while` loops
- `for` loops
- `if`, `elif`, `else`
- `break` and `continue`
- `in` operator
- f-strings
- User input

## Features
- Displays available fruits and masalas
- Lets the user select multiple fruits
- Validates fruit and masala choices
- Allows confirmation before preparing the fruit chaat
